# Security policy

## Scope

This repository contains static documents; it does not operate a service or issue
identity credentials, bank tokens, certificates, or audit records.

## Reporting a concern

If GitHub's private vulnerability reporting is enabled for this repository, use
the **Security** tab to submit a report. Otherwise, contact the repository
maintainer through a non-public channel. Do not include passwords, active tokens,
private keys, or real customer data in a public issue.

## Public repository history

Removing information from the current files does not remove it from earlier
commits, clones, caches, or copies. If a credential was ever committed, revoke or
rotate it. For sensitive information in prior commits, use GitHub's documented
sensitive-data removal process; rewriting history alone cannot remove other
people's copies.
